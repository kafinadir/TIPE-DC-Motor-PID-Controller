# TIPE-DC-Motor-PID-Controller
Conception et réalisation d'un système d'asservissement de vitesse pour moteur électrique dans le cadre du TIPE (CPGE MP).
Modélisation des équations dynamiques du système, implémentation d'un correcteur PID sur microcontrôleur Arduino et validation expérimentale des performances (temps de réponse, précision, stabilité) via l'acquisition de données capteurs.
### Technologies : 
Arduino (C++), Python (analyse/simulation), Électronique, Automatique.
